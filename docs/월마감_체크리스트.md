# 월마감 체크리스트 · 중계고기파티 재고관리

| 항목 | 내용 |
|------|------|
| 문서명 | 월마감 운영 체크리스트 |
| 대상 | 매장 관리자 · 사장님 |
| 대상 앱 | GAS 웹앱 (`webapp/`, UI `2026-11-08-j88` 기준) |
| 대상 시트 | `원재료입고`, `원재료관리`, `원재료_실시간재고`, `pos판매내역`, `거래처매입누적`, `발주내역` |
| 작성 목적 | 매월 같은 순서로 마감하여 누락·조기마감·이월 오류를 막는다 |

---

## 0. 한 줄 요약

**당월 입고·검수·검증·재고계산이 끝난 뒤에만** 사이드바 **배치작업 → 월마감 진행**을 누른다.  
월마감은 **이번 달 행을 지우지 않고**, 남은 재고를 **다음 달 이월재고**로 같은 시트에 추가한다.

---

## 1. 월마감이 실제로 하는 일

웹앱 **월마감 진행** (`jobMonthlyClose`) 동작:

1. `원재료_실시간재고`에서 **가장 최근 기준월**(예: `2026-11`)을 찾는다.
2. 그달 각 원재료의 **현재고(J)** 를 읽는다. (비어 있으면 이월+입고−사용+조정입고−조정로스로 계산)
3. **다음 달**(예: `2026-12`) 행을 만들거나 덮어쓴다.
4. 다음 달 행: `이월재고 = 이번 달 현재고`, `입고·사용·조정입고·조정로스 = 0`, `현재고 = 이월재고`
5. **이번 달 행은 그대로 남는다.**

주의:
- 재고·검수 화면은 항상 **최신 기준월만** 본다. 월마감 직후 UI는 다음 달로 바뀐다.
- 월마감은 POS·입고·거래처잔액을 **동결(잠금)하지 않는다.**
- 같은 다음 달 행이 이미 있으면 **그 행을 다시 채운다**(중복 추가가 아닐 수 있음).

---

## 2. 언제 돌리나

| 시점 | 권장 |
|------|------|
| 권장일 | **해당 월 영업 종료 후**, 마지막 날 입고·POS까지 반영된 뒤 |
| 가능 시각 | 당월 명세서·판매가 더 이상 안 들어올 때 |
| 하지 말 것 | 미검수 입고가 남아 있거나, 재고계산을 안 돌린 상태에서 월마감 |

매장 PC는 매일 **23:00 강제종료**된다. 월말에는 마감 작업이 23시 전에 끝나도록 한다.

---

## 3. 마감 전 준비 (당일 체크)

인쇄하거나 시트에 복사해 두고, 완료란에 ✅ 표시한다.

### A. POS · 매장 PC

- [ ] 매장 PC가 켜져 있고, 작업 스케줄러에 아래 3개가 있는지 확인  
  - `중계고기파티_OKPOS수집` (30분)  
  - `중계고기파티_일별날씨`  
  - `중계고기파티_매장PC강제종료` (23:00)
- [ ] 구글시트 `pos판매내역`에 **마감월 마지막 영업일** 판매가 있는지 확인  
  - 웹앱 메뉴 **POS 판매내역**에서 해당 날짜 구간으로 조회해도 됨
- [ ] (누락 시) 매장 PC에서 OKPOS 수집을 한 번 더 실행하거나, 담당자에게 `period=month` 수집을 요청

성공 신호: 마지막 영업일 저녁 매출 행이 시트/POS 화면에 보인다.

### B. 명세서 · OCR

- [ ] Drive **입고대기** 폴더에 남은 사진이 없는지 확인
- [ ] 웹앱 사이드바 **배치작업 → 1. 입고대기 대량OCR** 실행
- [ ] 메시지가 “이미지 없음” 또는 처리 완료인지 확인 → 파일은 **처리완료**로 이동됐는지 확인

성공 신호: 입고대기 폴더 비어 있음, `원재료입고`에 당월 명세가 들어옴.

### C. 원재료 코드

- [ ] 사이드바 **원재료 코드 관리** 열기
- [ ] **미등록** 품목이 있으면 대표 등록 또는 별칭(부모대표코드) 연결 후 **저장**
- [ ] 필요 시 **원재료입고반영** 실행 (수량 재계산)

성공 신호: 당월 입고에 코드 비어 있는 필수 식재료가 없다. (등록제외·쿠폰 등은 예외)

### D. 실물 검수

- [ ] 메뉴 **실물 검수** → 필터를 미검수(`pending`)로 두고 당월 건 확인
- [ ] 실물과 맞으면 검수 반영 → 상태가 **반영완료**
- [ ] 발주와 연결된 건은 입고완료 매칭까지 확인

성공 신호: 당월 미검수 건수 0 (의도적 보류 분만 남김 — 보류면 월마감 전에 메모).

### E. 거래처 금액 검증

- [ ] 메뉴 **거래처 금액 검증**
- [ ] 상단 **검증 계산**(또는 동일 기능 버튼) 실행 → `jobRebuildVendorBalances`
- [ ] 경고(불일치) 뱃지 건만 열어 전일채권·회수금·명세서금액 확인 (주류는 회수합계 공식)
- [ ] 틀린 OCR·중간결제는 시트/검수 쪽에서 수정 후 **검증 계산 재실행**

성공 신호: 검증 대상 거래처의 치명적 불일치가 해소됐거나, 남은 건 사유가 적혀 있다.

### F. 실시간 재고 계산

- [ ] 메뉴 **재고 및 발주 관리**
- [ ] **실시간 재고 계산** 버튼 실행 (`jobCalculateInventory`)
- [ ] 완료 메시지에 **기준월 = 마감하려는 달**인지 확인
- [ ] 샘플 3~5개 품목(고기·주류·야채 등)의 이월/입고/사용/현재고가 납득되는지 확인
- [ ] 필요 시 시트에서 **조정입고·조정로스** 입력 후 재고 계산 재실행
- [ ] 안전재고·부족수량이 이상한 품목만 짧게 메모

성공 신호: 당월 `원재료_실시간재고`의 현재고가 최신 계산 결과다.

### G. 백업 (권장)

- [ ] 구글시트 **파일 → 사본 만들기**  
  이름 예: `재고_월마감전_2026-11`
- [ ] 또는 시트 상단 **버전 기록**에 “2026-11 월마감 직전” 메모

성공 신호: 마감 실패 시 되돌릴 사본/버전이 있다.

---

## 4. 월마감 실행

순서 고정:

1. [ ] 위 **3장 A~F** 전부 완료(또는 보류 사유 기록)
2. [ ] 웹앱 사이드바 **배치작업 → 2. 월마감 진행** 클릭
3. [ ] 확인 창 문구 읽기  
   > 이번 달 기록은 그대로 두고, 남은 재고를 다음 달 기초재고로 추가할까요?
4. [ ] 확인 후 실행
5. [ ] 완료 메시지 확인 예:  
   - `2026-11 행은 그대로 두었습니다.`  
   - `남은 재고를 2026-12 이월재고로 … 개 만들었습니다.`  
   - `다음 달 입고, 사용량, 조정입고·로스는 0입니다.`

실패 시:
- 메시지를 캡처한다.
- **같은 달 월마감을 연속으로 여러 번 누르지 않는다.** (다음 달 행이 덮어써질 수 있음)
- 사본/버전으로 상태 확인 후, 담당자·개발과 함께 재시도한다.

---

## 5. 마감 직후 확인 (10분)

- [ ] 구글시트 `원재료_실시간재고` 필터  
  - 이전 달 행: 그대로 존재, 현재고·입고·사용 수치 유지  
  - 새 달 행: `이월재고 = 이전 달 현재고`, 입고·사용·조정 = 0
- [ ] 웹앱 **재고 및 발주 관리**를 새로고침 → **기준월이 다음 달**로 보이는지 확인
- [ ] 주요 코드 3개: 새 달 이월재고 = 직전 달 현재고 인지 대조
- [ ] (선택) 다음 영업일 발주가 필요하면 **재고 및 발주**에서 카톡 문구 복사·`발주내역` 저장

## 6. 월중 루틴 (마감을 쉽게 만드는 습관)

| 주기 | 할 일 | 화면 |
|------|--------|------|
| 매일 | 명세서 사진 업로드 → OCR → 미등록 연결 → 검수 | 입고대기 OCR, 원재료 코드 관리, 실물 검수 |
| 매일 | 매장 PC 수집 정상(매출 누락 방지) | 스케줄러 / POS 판매내역 |
| 주 1~2회 | 거래처 검증 계산, 경고 건만 처리 | 거래처 금액 검증 |
| 주 1회 | 재고 계산 후 부족·발주 | 재고 및 발주 관리 |
| 월말 | 본 체크리스트 3→4→5장 | 월마감 진행 |

## 7. 자주 하는 실수

| 실수 | 결과 | 막는 법 |
|------|------|---------|
| 미검수 입고가 남은 채 월마감 | 다음 달 이월이 작게 잡힘 | 검수 0건 확인 후 마감 |
| 재고계산 없이 월마감 | 오래된 현재고가 이월됨 | 마감 직전 **실시간 재고 계산** |
| 마지막날 POS 누락 | 사용량이 적어 재고가 부풀음 | `pos판매내역` 마지막일 확인 |
| 월마감 너무 이름 | UI가 다음 달만 보임, 당월 입고 처리가 헷갈림 | 당월 입고 끝난 뒤에만 실행 |
| 월마감 연타 | 다음 달 행이 반복 덮어씀 | 성공 메시지 확인 후 1회만 |
| 23시 강제종료에 작업 중 끊김 | 저장 안 된 작업 소실 | 22:30 전 마감 완료 |

## 10. 문서 범위 밖 (나중에 개선)

현재 앱에 없거나 문서만으로는 대체하는 항목:

- 재고·검수 화면의 **지난달 기준월 선택**
- 월마감 전 **자동 차단**(미검수·미매핑 있으면 버튼 비활성)
- 월간 매입/사용/손실 **리포트 PDF**
- 거래처 잔액 **월말 스냅샷 잠금**
- 카톡 발주 **자동 전송**

운영은 본 체크리스트로 유지하고, 위 항목은 별도 개발 과제로 진행한다.
