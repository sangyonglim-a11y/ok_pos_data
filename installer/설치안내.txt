중계고기파티 — 매장 PC OKPOS + 날씨 수집 에이전트 v1.1.1

[전원 시간]
- 보통 오전 11시 ON
- 매일 오후 11시(23:00) 강제 종료 (작업 스케줄러)

[자동 실행]
1) POS 판매내역: 30분마다 (영업시간 11:00~23:00만 실제 수집)
2) 일별날씨: 매일 11:40 · 19:10
3) PC 강제 종료: 매일 23:00 (shutdown /s /f /t 0)

[처음 설치]
1. OkposAgentSetup.exe 실행
2. 설치 폴더에 USB의 설정 파일 복사 (config.json, okpos-inventory.json)
3. 바탕화면 "OKPOS 판매수집" 한 번 실행
4. 작업 스케줄러 확인
   - 중계고기파티_OKPOS수집
   - 중계고기파티_일별날씨
   - 중계고기파티_매장PC강제종료

[업데이트]
새 OkposAgentSetup.exe 다시 실행 (설정 유지, 자동 수집 등록 체크)

[삭제]
Windows 설정 → 앱 → 중계고기파티 OKPOS 수집 → 제거
(강제종료 작업도 함께 지우려면 작업 스케줄러에서
 중계고기파티_매장PC강제종료 수동 삭제)
